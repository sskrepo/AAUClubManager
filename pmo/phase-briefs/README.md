# Phase Kickoff Briefs

One brief per phase, filed BEFORE the phase begins. The TPM owns these.

Filename: `PHASE-{N}-kickoff.md`

Format and protocol: [dev-agent-team/shared/phase-kickoff-brief.md](../../../dev-agent-team/shared/phase-kickoff-brief.md)

## What's here

- [PHASE-0-kickoff.md](PHASE-0-kickoff.md) — Foundation
- (PHASE-1-kickoff.md — filed when Phase 0 exits)
- (PHASE-2-kickoff.md — filed when Phase 1 exits)
- ...

## How to use

1. When TPM files a brief, it's pinned in `pmo/dashboard.md` under "📋 Current Phase Kickoff"
2. The brief lists external dependencies bucketed by urgency:
   - 🚨 Critical path — start within 24h
   - 🟡 Mid-phase — start within 1-2 weeks
   - 🟢 Nice-to-have — can wait
3. As you complete each item, mark it `[x]` in the brief
4. When all 🚨 + 🟡 items are done and agents finish their work, phase exit can happen
