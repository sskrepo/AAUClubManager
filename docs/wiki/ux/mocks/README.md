# UI Mocks

One subdirectory per phase: `phase-{N}/{flow-name}.md`

Owned by UX Designer. Filed BEFORE Architect's OpenAPI spec is finalized.

Format and protocol: [dev-agent-team/shared/phase-deliverables-protocol.md](../../../../dev-agent-team/shared/phase-deliverables-protocol.md)

## When mocks are produced

Per phase, UX produces a mock for every flow that:
- Has a user-facing screen
- Involves form input, multi-step flow, or complex state
- Changes navigation
- Is a critical persona task

Skip for: backend-only flows, admin one-time setups, automated jobs.

## Approval gate (Gate 1)

Mocks are reviewed alongside the PDD. See [pdd/README.md](../../pdd/README.md).
